# Docs

If you cloned the repo to run Baahar, start here:

| File | What it is |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the CLI, scorer, briefing, and Pocket Mode fit together |
| [FIELD_TEST.md](FIELD_TEST.md) | Blank outdoor-walk form. **No walk has been recorded yet.** |
| [SOURCES.md](SOURCES.md) | Data sources and re-verification dates |
| [DOD.md](DOD.md) | Challenge checklist with honest status |
| [NEEDS_HUMAN.md](NEEDS_HUMAN.md) | TabPFN licence and other human-only steps |
| [adr/](adr/) | Stack choice and the Tinker outcome |
| [SCENARIO_DRILL.md](SCENARIO_DRILL.md) | Offline persona drill against the real CLI/UI, not a park walk |
| [media/](media/) | Screenshots and the recorded WAIT demo |

The other markdown files in this folder are research protocols and review notes
from closed modelling studies. They stay so [`eval/RESULTS.md`](../eval/RESULTS.md)
can cite them. They are not the product you run with `uv run baahar brief`.
