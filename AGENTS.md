# AGENTS.md — Baahar

Operating rules for any agent (human or AI) touching this repository.
Read this before you change anything.

## What this project is

**Baahar** (बाहर — "outside") is an open-source AI agent that finds
Bengaluru's **next safe outdoor hour** from air quality + heat + rain, speaks a
~30-second park briefing generated by an open model, then enters **Pocket Mode**
so the phone goes dark while the human actually walks.

Built for the [DEV Hacktoberfest Open-Source AI Challenge Week 1: Touch Grass](https://dev.to/challenges/hacktoberfest-week1-2026-10-05).

## Non-negotiable constraints

1. **No credit card.** Never add a service that requires a card signup
   (DigitalOcean, MongoDB Atlas free tier, etc.). If a partner promo walls on a
   card, abort cleanly, document it in `docs/NEEDS_HUMAN.md`, and ship the
   fallback.
2. **Limited disk.** Never download multi-GB model weights into this repo or
   this laptop. Fine-tuning is **hosted** (Tinker). TabPFN is an *optional*
   install extra because it pulls PyTorch. Baahar must stay fully functional
   with **zero** keys and **zero** heavy packages.
3. **Honest numbers.** Every number in `eval/RESULTS.md` must trace to a real
   run. Raw machine-readable output lives in `eval/raw/`. If a test was not
   run, write `SKIPPED` and say why. Never invent a benchmark, an API shape, or
   a field-test result.
4. **New project only.** This is not Aaji's Pill Clerk. Started inside the
   challenge window.
5. **India-first.** Bengaluru. Indian NAQI (CPCB), Indian outdoor reality
   (heat, monsoon-exit, dust). Never relabel a US AQI number as Indian NAQI.
6. **Screen = shortest part.** If a feature makes the happy path longer than
   ~3 interactions before Pocket Mode, it is the wrong feature.
7. **New to software engineering** (the author). Keep the repo approachable:
   one-command quickstart, real tests, readable history, no clever tricks.

## Architecture rules

- `src/baahar/` is the library. `data/` holds curated + recorded inputs.
  `scripts/` holds reproducible job runners. `eval/` holds results and raw logs.
- Every network call must: have a timeout, be retry-safe, and have a recorded
  fixture fallback under `data/samples/`.
- Never let a silent failure produce a cheerful answer. If the air-quality API
  is down, Baahar says so — it does not return an empty "looks fine" briefing.
- Safety beats enthusiasm: hazardous air or extreme heat ⇒ `SKIP`, in plain
  language. Never pep-talk a user into bad air.
- Not a medical device. Copy must stay informational.

## Testing rules

- `pytest` must pass **offline**. No network in the default test run.
- Tests marked `@pytest.mark.network` or `@pytest.mark.gemini` are opt-in.
- Fixtures are recorded real responses, never hand-written fantasy payloads.

## Before you commit

```bash
uv run pytest
uv run ruff check .
```

Both must be green, and `pytest` must pass with **no network**. Then write a
conventional commit that explains *why*.

Install: `uv sync --group dev` for the normal loop. Add `--group ml` only when
you actually need TabPFN (it pulls PyTorch, ~2.5 GB).

## Definition of Done

See [`docs/DOD.md`](docs/DOD.md). Short version: public repo, working `brief`
flow, TabPFN **and** heuristic scorer, Gemma briefing, honest `eval/RESULTS.md`
with a documented failure, offline mode, `post.md` draft, `docs/FIELD_TEST.md`
that is honest about what has and has not happened, MIT license, and prize
categories listed only for tech actually used.

## Secrets

`.env` is gitignored. `.env.example` is complete and committed. Never print a
secret value, never paste one into a doc, a log, an eval artifact, or the DEV
post.
